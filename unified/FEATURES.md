## رفتار آنلاین/آفلاین

- **همیشه آفلاین‌اول**: هر تغییر اول در `localStorage` (`morabbi_db_v23`)، سپس `API.push` به سرور.
- **آفلاین**: نوشت‌ها در صف IndexedDB (`morabbi_sync_queue`)؛ flush روی رویداد `online` + تایمر ۶۰ ثانیه؛ حداکثر ۸ تلاش.
- **آنلاین**: pull هر ۶۰ ثانیه (reports/lessons/people/tasks/tracker/notifications/methodologies)، ادغام با `sid`.
- **ورود**: محلی اول (فوری)، بعد آنلاین (موفقیت → توکن + نگاشت `serverId`؛ شکست → toast «حالت آفلاین» و ادامه با داده‌های محلی).
- **`/api/*` هرگز cache نمی‌شود** (SW فقط shell را cache می‌کند).

## قابلیت‌های PWA

- `manifest.webmanifest`: RTL، `fa-IR`، standalone، آیکون 192/512 (+maskable)
- `sw.js`: cache shell (network-first برای navigation، cache-first برای استاتیک)، `sync` event (`morabbi-sync`)، `push` + `notificationclick` (آمادهٔ Web Push)
- **نصب**: Chrome/Edge دسکتاپ و اندروید؛ در قاب اندروید همان PWA داخل WebView است
- VAPID keys در `server/.env` (حالا خالی — فعال‌سازی push بعداً)
