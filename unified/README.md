# مورابی یکپارچه (Morabbi Unified) — نسخه ۴.۰.۰

سامانه تربیتی «نهضت تربیتی حضرت سیدالشهدا (ع)» در یک بسته واحد: **PWA آفلاین‌اول** + **بکند Next.js** + **قاب اندروید**.

این نسخه، دو نسخه‌ی پیشین را در هم ادغام کرده است:

| نسخهٔ پیشین | آنچه از آن گرفتیم |
|---|---|
| v2.0.0 (Next.js + Prisma + SQLite) | کل بکند: ۴۲ مسیر REST، احراز هویت سشن‌محور، امتیاز/تقدیر/ارزیابی |
| v23 (اپ تک‌فایل آفلاین) | کل رابط کاربری: ۳۳ نما، local-first روی localStorage، امتیازدهی v23 |

نتیجه: اپ موبایلی v23 حالا به سرور وصل می‌شود (local-first + صف سینگ) و همان API قدیمی v2.0.0 را می‌سازد؛ React SPA حذف شده و صفحهٔ اصلی `Next` به PWA ریدایرکت می‌کند.

## شروع سریع (کلون و اجرا)

```bash
# ۱. کلون
git clone <this-repo> && cd <repo>

# ۲. نصب و راه‌اندازی
cd unified/server
npm install
npm run db:restore          # بازسازی prisma/dev.db از dev.db.zip (داده‌ی کامل قرآن/حدیث)
cp .env.example .env        # سپس مقادیر واقعی را پر کنید
npx next dev -p 3015
```

- بکند + PWA: <http://localhost:3015/app/index.html>
- سلامت API: <http://localhost:3015/api/health>

> **داده‌ی قرآن** (۶۲۳۶ آیه) به‌صورت `prisma/dev.db.zip` (۰٫۷ مگابایت) در ریپو است؛ `npm run db:restore` آن را به `prisma/dev.db` (۲٫۸ مگابایت) استخراج می‌کند.
>
> **حدیث‌ها** (۱۶۸ روایتِ کاملِ بحارالانوار ≈ ۱۰۸ مگابایت) برای سبک‌ماندنِ ریپو داخلِ zip نیستند؛ برای افزودن‌شان `npm run import:hadith` را با دسترسی به منبع خام `E:\بحارالانوار` اجرا کنید. (قرآن نیز با `npm run import:quran` از `E:\corpus.quran.com` قابل‌بازسازی است.)

> **دستیار هوشمند (AI):** برای فعال‌شدن پاسخ‌های واقعی LLM یکی از دو حالت را برقرار کنید:
> - متغیرهای `ZAI_BASE_URL` و `ZAI_API_KEY` در `.env` را پر کنید، **یا**
> - `cp .z-ai-config.example .z-ai-config` و `baseUrl`/`apiKey` را بنویسید.
>
> بدون این‌کار دستیار به‌صورت rule-based (آفلاین) پاسخ می‌دهد.

## ویژگی‌ها (خلاصه)

- **گزارش روزانه**: الگوی ۴ مرحله‌ای (ارائه/تفکر/مباحثه/ارائه به مربی) + تفکیک ۳ گروه (استقامتی/نیمه‌سرعتی/سرعتی) + چرخهٔ وضعیت پیش‌نویس→ارسال→تأیید/برگشت
- **طرح درس**: اهداف/مراحل چهارگانه/وسایل/منابع + ارزیابی ۱۷+۱۲ معیار
- **افراد و حضور/غیاب** + **صورتجلسه** + **تکالیف** + **برنامهٔ روزانهٔ معنوی** (نماز/قرآن/ذکر/روزه/تدبر)
- **ارزیابی** با معیارهای وزنی + **امتیازدهی خودکار** (۹ قانون) + **تقدیر** و **تابلوی رتبه‌بندی**
- **دستیار هوشمند** (AI) + **جستجوی سراسری** + **قرآن و حدیث** + **اطلاعیه‌ها** + **تقویم** + **آمار**
- **خروجی** در ۵ فرمت (PDF/Word/TXT/JSON/CSV) + **بک‌آپ/ریستور** JSON
- **آفلاین‌اول**: همهٔ تغییرات اول در localStorage، بعد sync به سرور؛ نوشت‌های آفلاین در صف IndexedDB
- **PWA**: نصب روی دسکتاپ/موبایل، Service Worker، آمادهٔ Push (VAPID)
- **حالت تیره**، RTL کامل، فارسی‌نویس
