# مستندسازی توسعه سامانه گزارش و طرح درس روزانه مربیان

## 📋 معرفی پروژه

این پروژه سامانه‌ای برای مدیریت گزارش‌ها و طرح‌درس‌های روزانه مربیان یک مجموعه آموزشی-مذهبی (شیعی) با چند شعبه است. هدف اصلی، تسهیل نظارت مسئول شعبه و مسئول مرکزی بر کار مربیان، ارزیابی کیفی (انسانی و هوشمند)، رفع اشکال، و تقدیر از برترین عملکرد در راستای آیه شریفه «وَالسَّابِقُونَ السَّابِقُونَ» است.

---

## 🏗️ معماری کلی

### نقش‌ها
| نقش | دسترسی |
|---|---|
| مربی | فقط داده‌های خودش |
| مسئول شعبه | شعبه خودش |
| مسئول مرکزی | همه شعب |
| مدیر سیستم | کل سامانه |

### ماژول‌های اصلی
1. گزارش روزانه (با قابلیت ضبط صوت و آپلود تصویر)
2. طرح درس
3. ارزیابی انسانی
4. ارزیابی هوشمند (AI)
5. رفع اشکال (کامنت‌گذاری روی متن)
6. سیستم امتیازدهی و تقدیر (السابقون السابقون)
7. داشبورد شعبه‌ای و مرکزی
8. پردازش رسانه (تبدیل صوت و تصویر به متن)
9. پایگاه‌داده قرآن با جستجوی فارسی/عربی

### فناوری‌ها
- **Frontend**: Next.js 16 + React 19 + Tailwind CSS 4 + shadcn/ui
- **Backend**: Next.js API Routes + Prisma ORM (SQLite)
- **AI**: z-ai-web-dev-sdk (LLM برای ارزیابی، ASR برای تبدیل صوت، VLM برای OCR)
- **زبان**: TypeScript
- **رابط کاربری**: فارسی، RTL، موبایل‌پسند، فونت Vazirmatn

### نکات طراحی

#### حریم خصوصی ( aligned با اصل اسلامی حفظ امانت)
- فایل‌های صوتی پس از پردازش به‌صورت خودکار حذف می‌شوند
- داده‌های ارزیابی فقط برای مربی و مسئول مربوطه قابل‌مشاهده است
- هیچ لیست «بدترین‌ها» نمایش داده نمی‌شود — فقط «سابقون» تقدیر می‌شوند

#### چارچوب اخلاقی-شرعی
- تقدیر انگیزه‌بخش است، نه وسیله تکبر (متناسب با حدیث «إنّما الأعمالُ بالنیّات»)
- ارزیابی هوشمند همیشه با برچسب «پیشنهاد»، تصمیم نهایی با مسئول است
- در متن تقدیر، به «تلاش و استمرار» اشاره می‌شود، نه فقط به عدد امتیاز

این پروژه با نیت «خدمت به کیفیت آموزش دینی و تسهیل نظارت شرعی بر کار مربیان» توسعه یافته است. در راستای حدیث شریف:

> **«إِنَّمَا الأَعْمَالُ بِالنِّيَّاتِ»**

امید است که این ابزار به رشد آموزش‌های دینی و تقدیر از تلاش‌گران در مسیر علم و عمل کمک کند.
